# Advayu

## Technologies Used

- **Node.js**: Backend runtime for executing JavaScript server-side.
- **Next.js**: React framework for building server-side rendered (SSR) and static web applications.
- **Prisma**: ORM for seamless database interactions.
- **PostgreSQL**: Relational database management system.
- **Material UI**: Component library for building user interfaces.
- **Shadcn**: UI components library. Installation guide: [Shadcn Docs](https://ui.shadcn.com/docs/installation/next)
- **Tailwind CSS**: Utility-first CSS framework for styling.

## Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/advayu/dashboard.git
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start development server**:

   ```bash
   npm run dev
   ```

4. **Before pushing changes**:
   - Create an optimized build:
     ```bash
     npm run build
     ```
